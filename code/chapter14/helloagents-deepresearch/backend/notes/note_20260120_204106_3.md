# 研究报告：RAG

RAG技术起源于2019年，由阿里云的研究团队提出，旨在通过检索和生成相结合的方式提高生成模型的性能。RAG技术广泛应用于问答系统、文档摘要、对话系统等领域。主流的RAG系统采用基于Transformer的架构，通过检索模块获取相关文档，然后将这些文档作为输入传递给生成模型。RAG技术的发展历程、应用场景和关键技术是本报告的核心洞见。
